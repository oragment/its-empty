# its empty

**English** · [简体中文](./README.zh-CN.md)

A Skill from **its** by **oragment**.

Upstream of **its shape**.

For when there is almost nothing to work with — no notes, no scraps, no clear place to begin.

## What it does

Helps you notice a few concrete things and write them down as short fragments.

Default aim: **3–5 usable fragments**.

Then it stops and hands off to **its shape** to begin Connect.

## What it does not do

It does not find your theme, choose a direction, or create a Work.

It only gets you from zero to enough material to start.

## Use when

- you feel blank
- you have no fragments yet
- you do not know where to begin

If you already have fragments, use **its shape**.

## Install

Copy or clone this folder into a supported skills directory, for example in Cursor:

- Project: `.cursor/skills/its-empty/`
- Personal: `~/.cursor/skills/its-empty/`

Then ask the agent to use **its empty**, or invoke it through your environment's Skill interface.

The skill instructions live in [`SKILL.md`](./SKILL.md).

## Related

- **its chaos** — too many fragments; thin until startable
- **its tight** — material exists, but thinking is stuck

empty / chaos / tight are upstream state Skills. **its shape** is where material takes form.
