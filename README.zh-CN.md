# its empty

[English](./README.md) · **简体中文**

来自 **its** by **oragment** 的 Skill。

是 **its shape** 的上游。

适合几乎没有材料可下手的时候——没有笔记、没有碎片、不知道从哪里开始。

## 它做什么

帮助你注意到几件具体的事，并把它们写成短碎片。

默认目标：**3–5 个可用碎片**。

然后停止，交给 **its shape**，从 Connect 开始。

## 它不做什么

不帮你找主题、定方向，也不生成 Work。

它只负责从 0 到「有足够材料可以开始」。

## 适用场景

- 感觉空白
- 还没有任何碎片
- 不知道从哪里开始

如果已经有碎片，请用 **its shape**。

## 安装

将本文件夹复制或克隆到支持的 skills 目录，例如在 Cursor 中：

- 项目级：`.cursor/skills/its-empty/`
- 个人级：`~/.cursor/skills/its-empty/`

然后让 agent 使用 **its empty**，或通过当前环境的 Skill 接口调用。

Skill 说明见 [`SKILL.md`](./SKILL.md)。

## 相关

- **its shape** — 主流程：Connect → Mainline → Structure → Work
- **its chaos** — 碎片太多；减载到可以开始
- **its tight** — 有材料，但思路卡住

empty / chaos / tight 都是上游状态 Skill。**its shape** 才是材料成形的地方。
